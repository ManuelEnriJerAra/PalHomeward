# PalHomeward

Server-side Palworld mod (UE4SS Lua) that aims to return a guild base worker Pal to its
**original owner's** storage when another guild member removes it from a shared base.

> **Status: PLAN / NOT IMPLEMENTED.** Nothing in this repository has been verified against
> a running Palworld server yet. See the development plan in [`docs/es/plan.md`](docs/es/plan.md)
> (Spanish original; English translation in progress).
